# M10 — Sky Island Hole 1 Vertical Slice

## Goal

지금까지의 시스템을 하나의 완전한 Hole 경험으로 통합한다.

## Build / Integrate

Sky Island Golf Club Hole 1:

- Tee
- Fairway
- Rough
- Bunker
- Green
- Water
- Cup/Flag
- landmark placeholder
- stylized bright materials
- sky/cloud environment
- readable target line

## Full Flow

Game Start
→ Hole Intro
→ Address
→ Aim
→ Club
→ Power
→ Impact
→ Swing
→ Launch
→ Ball Camera
→ Landing
→ Roll
→ Stop
→ Next Shot
→ Green
→ Putt
→ Hole In
→ Result

## Quality

아직 final art가 없어도 composition을 의도적으로 만든다.

참고 이미지와 비교:

- character scale
- camera distance
- course depth
- UI density
- aim readability
- wind readability

Gap은 문서화한다.

## Exit Criteria

한 번의 Play Session에서 Hole 1을 시작부터 끝까지 완료할 수 있다.

Critical Console Error 0.

표준 보고 형식으로 종료하라.
